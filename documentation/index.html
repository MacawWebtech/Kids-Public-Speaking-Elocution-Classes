SpeakUp Stage HTML Template

A multi-page Bootstrap 5 template for kids' public speaking and elocution academies, with a full parent dashboard. Built with semantic HTML, one custom stylesheet, and vanilla ES6+ JavaScript.

Getting started

  1. Unzip speakup-stage.zip.
  2. Open index.html in a browser, or serve the folder locally for the best result (some browsers limit file:// features):
cd speakup-stage
python3 -m http.server 8080   # or: npx serve .
# open http://localhost:8080

No build step is needed. Bootstrap 5.3.3, Bootstrap Icons 1.11.3 and Chart.js 4.4.4 are bundled locally in assets/js/plugins/, so the template works offline. Google Fonts and the photos load from CDNs.

Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel). Point your host's 404 page to pages/404.html (an .htaccess is included for Apache).

Colors & theme

All colors are CSS custom properties at the top of assets/css/style.css. Change them once and the whole site follows. Search for TODO to find every customization point.

Navy #1B2A4EOrange #FF7A1AOrange #FF7A1ATeal #2EC4B6Cream #FFF9EE
:root {
  --su-navy:   #1B2A4E;  /* trust: headings, nav, footer   */
  --su-orange: #FF7A1A;  /* energy: highlights, spotlight  */
  --su-orange:  #FF7A1A;  /* CTA buttons                     */
  --su-teal:   #2EC4B6;  /* success, progress, meters       */
  --su-cream:  #FFF9EE;  /* page background                 */
  /* AA-safe text shades used for small text */
  --su-orange-600: #C2410C;
  --su-teal-700:  #0F766B;
}

Semantic roles (--su-bg, --su-surface, --su-text, --su-heading, --su-border) are what components use, so dark mode only needs to re-map those (see dark-mode.css). Primary buttons use navy text on orange (5.05:1) to keep the exact brand orange while passing WCAG AA.

Fonts

Headings use Baloo 2, body text Nunito, and small handwritten accents Caveat. To change them, edit the Google Fonts <link> in each page's <head> and the three variables:

--su-font-head: "Baloo 2", "Fredoka", system-ui, sans-serif;
--su-font-body: "Nunito", system-ui, sans-serif;
--su-font-hand: "Caveat", cursive;

To self-host (best for performance and privacy), download the WOFF2 files into assets/fonts/, add @font-face rules at the top of style.css, and remove the Google Fonts link.

Content & images

  • All photos are your own images, stored locally in assets/images/ (no external image hosts). Each has explicit width/height (no layout shift) and loading="lazy" below the fold.
  • A person keeps the same photo everywhere they appear (a coach on the home page, team grid and profile; a child in the dashboard). Every other photo is used once.
  • assets/images/photo-credits.txt lists every image slot and its photo URL.
  • Use your own photos (recommended before launch): save WebP files in assets/images/, then replace the src/srcset of each <img> and update its alt. Keep the same aspect ratio as the width/height attributes. If you use the generator workflow, edit SLOTS, COACH and PARENT in one place instead.
  • Sample people, prices (₹), dates and achievements are realistic placeholders. Search for TODO and for the sample domain speakupstage.example before launch.
  • Only the decorative stage shapes (curtain edges, spotlight beam, waves) are inline SVG, so they recolor in dark mode.

Confidence Meter

The signature motif: a sound-wave bar that fills as it scrolls into view. Add data-animate for a gentle live wave (disabled for reduced motion).

Storytelling78%
<div class="cmeter">
  <div class="cmeter-head"><span>Storytelling</span><span class="val">78%</span></div>
  <div class="cwave" role="img" data-level="78" data-bars="20" aria-label="Storytelling: 78 out of 100"></div>
</div>
<!-- color variants: .cwave.orange, .cwave.orange · size: .cwave.sm -->
<!-- gauge: <div class="gauge" data-value="82">…</div> (see dashboard/progress.html) -->

After loading content dynamically, call window.SUBuildWaves(container) to render new meters.

Forms & integrations

Any <form class="su-form"> gets friendly client-side validation. Set a custom message per field with data-msg; errors are announced with aria-describedby and focus moves to the first problem.

<form class="su-form" data-endpoint="https://formspree.io/f/YOUR_FORM_ID" data-success="ok-id">
  <div class="field">
    <label class="form-label" for="age">Child's age</label>
    <input class="form-control" id="age" type="number" min="5" max="16" required
           data-msg="Please tell us your child's age (5 to 16).">
  </div>
</form>
<div class="form-success" id="ok-id">Thanks!</div>
  • Formspree: replace YOUR_FORM_ID in data-endpoint. Placeholder endpoints containing YOUR_ are simulated so the demo works offline.
  • Netlify Forms: add name="contact" data-netlify="true" to the form and set data-endpoint="/".
  • Mailchimp / ConvertKit: newsletter forms use the field name EMAIL; paste your list's form action URL into data-endpoint.
  • Google Maps: on contact.html and competition-details.html, replace the .map-ph block with your embed <iframe> (snippet in the TODO comment).
  • Booking calendar: the demo form can be swapped for a Calendly or Cal.com embed (TODO in contact.html).
  • Stripe / PayPal: the buttons in dashboard/payments.html are placeholders; wire them to Stripe Checkout and PayPal Smart Buttons from your backend.
  • Login: the auth forms validate and then redirect to the demo dashboard (data-redirect). Connect your own auth provider.

Dark mode & RTL

Dark mode follows the visitor's system setting on first visit (prefers-color-scheme), then remembers their choice. An inline script in <head> applies it before paint, so there is no flash. All overrides live in dark-mode.css under [data-theme="dark"]; charts re-theme automatically.

RTL: the RTL button switches <html dir="rtl">, swaps Bootstrap to bootstrap.rtl.min.css and applies rtl.css. For an Arabic or Hebrew site, set dir="rtl" lang="ar" on <html>, point #bs-css to the RTL file and remove the toggle buttons.

Accessibility

  • Skip link, visible focus rings, landmarks and one <h1> per page with a logical heading order.
  • Color pairs checked for WCAG 2.1 AA contrast; touch targets are at least 44×44px.
  • Icons are decorative (aria-hidden); icon-only buttons have aria-labels. Meters, gauges and charts have text alternatives.
  • Keyboard support for menus, tabs, accordions, modals, filters, child tabs (arrow keys) and the dashboard drawer (Esc closes).
  • Animations respect prefers-reduced-motion and are lighter on small screens.

SEO & performance

  • Unique titles (≤60 characters) and meta descriptions (150–160 characters) on every page, plus canonical, Open Graph and Twitter tags.
  • JSON-LD: EducationalOrganization + LocalBusiness, Event (competitions), Course (programs), FAQPage, BlogPosting, Person (coaches).
  • sitemap.xml and robots.txt included (dashboard is noindex). Replace https://www.speakupstage.example with your domain.
  • Locally hosted photos with explicit sizes, lazy loading, deferred scripts, no render-blocking JS, local libraries. For best scores, self-host fonts and enable gzip/brotli (see .htaccess).

Parent dashboard

Nine pages share one sidebar layout (dashboard.css). Each data area has a skeleton state (data-skeleton), and empty states are shown for no batches, no results and no notes. Charts use Chart.js and show a placeholder box if the library fails to load.
